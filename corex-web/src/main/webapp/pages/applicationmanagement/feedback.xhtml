Feedback for Application Admin

Share ideas, rough edges, workflow blockers, or improvement requests. Your note will be sent privately to the application admin so the product can keep getting better.

Send Feedback

Keep it specific. Mention the screen, the problem, and the improvement you want.

Helpful Tips

Strong feedback is easier to act on and quicker to fix.
Mention the page
Say which page, flow, or step needs attention.
Describe the friction
Explain what feels slow, confusing, repetitive, or missing.
Suggest the better path
If you know the improvement you want, write it directly.
